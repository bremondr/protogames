# Hex maps and procedural generation: reading list

> **Status: reading list, not documentation of Protogames.** Links collected while working on tile and map generation; nothing here describes what the app does (for that see [../TILE_GENERATION_EXPLANATION.md](../TILE_GENERATION_EXPLANATION.md)). Links last opened: 2026-10-26 (all four answered).

Short descriptions are the page titles; the pages themselves were not summarised.

## HexCastle

- [HexCastle](https://hexcastle.andriibabintsev.com/): a hex-tile site by Andrii Babintsev, kept as an example of a hex map built from tiles.

## Wave Function Collapse on hex maps (Felix Turner)

- [hex-map-wfc on GitHub](https://github.com/felixturner/hex-map-wfc): the source repository.
- [Building a Procedural Hex Map with Wave Function Collapse](https://felixturner.github.io/hex-map-wfc/article/): the article that explains the approach.
- [Hex Map Toy](https://felixturner.github.io/hex-map-wfc/): the live demo that goes with the article.
