# Research

Notes that inform decisions but do not describe what Protogames does. Nothing in this folder is a specification: for what exists, read [../SPECIFICATION.md](../SPECIFICATION.md), [../PLAYTEST.md](../PLAYTEST.md) and the rest of the reference documents listed in [../README.md](../README.md).

| Item | What it is | How it was made, how much to trust it | Last verified |
|---|---|---|---|
| [board-topologies/](board-topologies/README.md) | Survey of how 25 published tabletop games structure their maps, with a photo, a schematic and a difficulty estimate per game. Input for deciding which kinds of boards to support. | Written from memory first, then checked against the games' rulebooks (rulebook and page named per row); photos are hotlinked from Wikimedia Commons with a credits table; schematics are our own SVGs. The facts about the games are checked; the *difficulty estimates* are one developer's guesses, not a plan. | 2026-10-26 (links); facts per rulebook as cited |
| [playtest-ideas.md](playtest-ideas.md) | Backlog of ideas for playtest mode, with what is already built and which GitHub issue tracks which idea. | Written by the maintainers; ideas, not commitments. | 2026-10-26 |
| [hex-maps-reading-list.md](hex-maps-reading-list.md) | Four links on hex maps and procedural generation (Wave Function Collapse). | Collected while working on tile generation; the pages are not summarised. | 2026-10-26 |

New research goes here when it is a survey, a backlog or a reading list. If it proposes a concrete feature, it is a proposal: see [../proposals/](../proposals/README.md).
